# Pull requests

These rules set a PR's metadata. Its title and body belong to whichever PR skill is in use.

When opening a PR:

- Assign it to me.
- Give it the milestone of the issue it closes. If it closes issues with different milestones, leave the milestone
  unset and tell me.
- Label it from the repo's existing labels, by what the change is. The closing issue's labels are a hint; its triage
  labels stay on the issue. If no existing label fits, add none.

All three are best-effort: if the forge rejects one, skip it and tell me.
